# 转发说明、练习任务和问题反馈

## 可以直接发给同学的消息

> 这是我整理的 CodeLoop coding agent 使用包，Python 包名是 minicode-py。你先解压源码 ZIP，打开 `CodeLoop/docs/handoff/README.md`，按“01 快速上手”安装和运行离线自检。
>
> 通过后配置你自己的模型 API Key、模型名和服务地址。先在练习项目里做一个只读任务，再试小范围修改。CLI 和本地网页 Dashboard 都可以用，配置完成后要在你想处理的项目目录启动。
>
> 包里带了配置模板、使用说明、排错说明和验收清单，不包含我的密钥或历史对话。模型调用额度由你自己的服务账号承担。出问题按下面的模板把现象、复现步骤和脱敏后的报错发给我即可。

交付人发送时附上 `CodeLoop-source-2026-09-18.zip` 与 `SHA256SUMS.txt` 即可；同名版本对应的 wheel 是可选安装方式。不要把个人 `.env`、虚拟环境和整个研究工作目录一并发送。

## 建议的三步试用

1. **只读熟悉项目**：“列出这个练习项目的主要文件，解释入口和执行流程。先不要修改任何文件。”检查回答是否对应真实文件，而不是只看文字流畅。
2. **小范围修改**：“给这个练习项目的一处输入校验补充明确错误提示，先说明准备改哪里，再进行修改。”使用可还原的目录；检查实际 diff，确认没有无关文件变化。
3. **验证结果**：“执行该项目已有的相关测试，列出执行命令、结果和仍未验证的部分。”核对终端/日志和实际输出，不只接受模型自述。

如果项目没有测试，先让 Agent 说明如何验证，不要把“没有测试可跑”当作通过。遇到需要批准的命令或文件访问时先检查操作目标。
