# 维护、源码入口与使用边界

## 当前交付基线

本次包版本是 `0.1.0`，交付标识是 `classmate-2026-09-18`。这个版本号不足以唯一标识源码，请同时保留 ZIP、`DELIVERY-MANIFEST.json` 和外部 `SHA256SUMS.txt`。清单中的 Git HEAD 只表示来源基线；当前工作区还有未提交修改，以清单中的文件哈希为准。

日常使用建议普通安装。已安装模块不依赖源码位置，但如果移动的是包含 `.venv` 的整个 `CodeLoop` 目录，仍需重建虚拟环境。升级时先保存当前交付包和自己的配置，然后在新目录解压新包，用原来的虚拟环境 Python 重新安装：macOS/Linux 执行 `"$CODELOOP_PY" -m pip install .`，PowerShell 执行 `& $codeLoopPy -m pip install .`。这些变量的设置方式见 01。

源码修改不会自动反映到普通安装，改完必须重装。准备持续开发时可把上述安装命令改为 `-m pip install -e .`，此时不要移动源码目录；交付自检专门验证普通安装，不用于验证 editable 安装。

旧包只可作为程序版本的回退来源。若未来版本更改了数据格式，重新安装旧包不等于数据也自动回退；先关闭进程并备份个人状态。

一次任务大体经过：当前工作目录 → 用户输入 → 运行环境与模型配置 → 模型/工具循环 → 审批、验证和结果 → 本地运行记录。CLI、Dashboard 和 headless 共享运行组件，但交互审批能力不同。

精简包保留运行源码，未保留完整 `tests/`、`scripts/`、`artifacts/` 和研发文档；不能直接把原仓库的全量 pytest / 质量门命令用于此包。若要正式接手开发，需要另行同步**与交付快照对应**的完整仓库、测试 fixture 和策展验收数据；公开仓库的 HEAD 不保证包含当前工作区修改。项目原始来源信息见根目录 `CONTRIBUTIONS.md`。

## 配置与个人数据

| 位置 | 用途与处理方式 |
| --- | --- |
| `~/.mini-code/.env` | 用户级模型、端点和密钥。自己保存，不放入问题反馈。Windows 对应用户目录中的 `.mini-code`。 |
| `~/.mini-code/settings.json` | 旧配置兼容回退。变更配置时注意旧值可能仍影响运行。 |
| `~/.mini-code/permissions.json`、`mcp.json`、`USER.md` | 已允许操作、外部工具和用户偏好，属于接收人的个人配置。 |
| `~/.mini-code/` 下的会话、运行日志、Memory 等 | 可能含提示词、代码片段和本地路径；迁移或排错前先识别内容。 |
| 目标项目下 `.mini-code/`、`.mini-code-memory/` 等状态目录 | 项目级配置与经验。不要当作普通源码随意提交或整体发送给别人。 |

进程环境变量优先于用户级 `.env`；旧配置还可能回退。目标项目的普通 `.env` 不负责主模型凭据路由。修改 Key 后退出并重启程序，再检查 `/config-paths` 和 `/model`。

备份前关闭 CLI、Dashboard 和后台任务。至少保留自己的用户级配置及需要的项目状态；备份包含密钥时应按密钥文件管理。卸载 Python 包不会自动清除个人状态，不要为排错直接清空 `~/.mini-code/`。

## 已知边界

- **模型能力依赖你选择的服务。** OpenAI-compatible 不保证所有服务都支持相同的工具调用、流式输出和用量字段。本地配置检查只证明格式和规则符合要求。
- **Mock 只用于链路检查。** 它不会真实推理、修复代码或证明远程服务可用。普通 mock 启动也不是全局禁网；交付自检脚本另做了隔离。
- **审批不是操作系统沙箱。** 无交互审批回调时（例如 headless），默认允许一部分有边界的小修改快速执行；交互 CLI 有审批回调时不走这条快速路径。如希望关闭父 Agent 快速修改，可在启动进程的终端设置 `MINI_CODE_PARENT_FAST_EDIT=0`；此项不要仅写进用户级 `.env`，当前配置白名单未包含它。
- **预算用于约束单轮工作。** 模板先给 20 次模型调用 / 20 万 token / 1 美元估算成本；复杂任务可能提早停止。未知模型计价或 provider 用量缺失时，本地成本统计不能替代服务商额度设置。
- **无界面运行不具备交互审批。** 需要人工输入或许可的步骤可能停止；headless 打印错误文字时也可能返回 0，自动化必须检查输出与任务产物。
- **子 Agent 和工作流有范围限制。** 异步探索/计划以只读任务为主；取消不是对所有阻塞网络调用的立即强制终止。
- **扩展功能没有随包配置。** MCP、远程 embedding、Hybrid Memory 和独立子模型都不是首次使用的必需项，需要额外服务、数据或授权。
- **本次没有替你调用真实付费模型。** 本次验证结果见 03；模型端到端和接收人平台验收由同学完成。
- **许可文件现状。** 当前仓库没有根目录 LICENSE，本次未擅自补写许可证或改变原有归属说明。
