## 同学电脑上的验收

按 [快速上手](01-快速上手.md) 执行具体命令，再勾选此表。

- [ ] Python 版本符合要求，虚拟环境与安装成功。
- [ ] 交付自检脚本返回通过，且退出码为 0。
- [ ] 已配置自己的主模型；清理临时 mock 开关后，配置检查输出 `Status: OK`，没有 `ERRORS`；如果模型名触发内置名单提醒，已对照自己的 provider 核实。
- [ ] 在新建练习目录发出只读任务；模型能引用该目录真实文件内容。
- [ ] 从第二个项目目录启动，确认操作目标变为该目录。
- [ ] 在可还原的练习项目完成一次小修改；人工检查 diff，执行该项目自己的验证命令。
- [ ] 能退出并重启 CLI；若使用会话恢复，确认恢复的是目标会话。
- [ ] 如需网页入口，Dashboard 能显示当前项目并完成一次对话。
- [ ] 清楚模型服务的用量查看方式，以及反馈问题时应去掉哪些内容。

只读和修改任务若输出“Error”、超时、预算耗尽或审批未完成，应记为未通过/未完成。不要因为进程退出码为 0 就勾选成功。

接收方可在存放 ZIP 的目录执行校验。macOS/Linux：

```bash
shasum -a 256 CodeLoop-source-2026-09-18.zip
```

Windows PowerShell：

```powershell
Get-FileHash .\CodeLoop-source-2026-09-18.zip -Algorithm SHA256
```

输出须与 `SHA256SUMS.txt` 中对应行一致。这是传输完整性校验，不是数字签名。
