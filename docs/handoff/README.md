# CodeLoop 同学使用交付包

交付日期：2026-09-18。项目名 **CodeLoop**，Python 包名 `minicode-py`，版本 `0.1.0`，运行命令 `minicode-py`。

这是基于交付当天**当前工作区**整理的精简运行源码包，包含未提交但运行必需的源码。它不是某个 Git 提交的完整归档，也不是已经完成全量生产验收的正式发行版。具体文件由交付包中的 `DELIVERY-MANIFEST.json` 标识。

## 先看哪份文档

| 文档 | 你要完成的事 |
| --- | --- |
| [01 快速上手](01-快速上手.md) | 安装、离线自检、填自己的模型配置、完成第一个任务 |
| [02 日常使用与排错](02-日常使用与排错.md) | 切换项目、CLI / Dashboard / headless、会话和故障处理 |
| [03 验收与交付清单](03-验收与交付清单.md) | 核对实际验证范围，记录自己电脑上的验收结果 |
| [04 维护与边界](04-维护与边界.md) | 看懂源码入口、升级方式、数据位置和已知限制 |
| [05 转发说明与问题反馈](05-转发说明与问题反馈.md) | 直接复制的交付消息、反馈模板和试用任务 |
| [最小配置模板](config/.env.example) | 配置自己的 OpenAI-compatible 模型服务 |

首次使用按 01 的顺序操作即可。先通过无需 API 的离线检查，再接入模型。只用默认功能时，需要 Python 3.11 或更新版本（本次验证使用 3.12），不需要 Node.js、GPU、Docker、向量模型或 MCP 服务。

## 包里有什么

- `minicode/`：Python 运行源码及 Dashboard 静态页面。
- `pyproject.toml`：依赖和命令行入口；`.env.example`：项目原始完整配置参考。
- `docs/handoff/`：这套中文使用文档、简化配置和自检脚本。
- `CONTRIBUTIONS.md`：项目来源及贡献说明，保留原文；其中深层审计链接需要完整仓库。
- `DELIVERY-MANIFEST.json`：快照标识、文件大小和 SHA-256 清单。

安装过程中 pip 可能联网获取构建工具和依赖。模型服务需要同学自己的账号、可用额度以及与该服务匹配的模型名和端点。本包没有附送模型访问权限。

## 交付范围

这份包可用于本地试用、日常编码和阅读运行源码。未包含原作者的 API Key、`.git` 历史、虚拟环境、会话、Memory、私人 Skill / MCP 配置、历史原型、完整测试与实验数据。安装包之外的个人状态由你在自己的电脑上新建。

先在练习目录或已有备份的项目里使用。CodeLoop 会把请求及完成任务所需的上下文发送给你配置的模型；工具允许时可修改文件或执行命令。具体行为和限制见 04。
