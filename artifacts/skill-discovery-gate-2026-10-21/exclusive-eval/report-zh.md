# Discovery Gate 与正文独占评测：最终对照报告

日期：2026-10-21。执行目录：`.repair-work/skill-exclusive-eval-2026-10-21/`（独占集）与 `.repair-work/skill-presel-verify-2026-10-21/`（旧模糊集 gate 批，`trials-gate/`）。

## 一、机制改动（生产代码，默认关闭）

1. **Discovery gate**（`minicode/agent_loop.py`）：路由层建议了可能相关的目录、且本轮零技能通道活动（browse/search/load 均未尝试，失败尝试也算已行动）时，在终答前注入一次提醒；**advisory-once，绝不否决终答**。配置 `skillSelection.discoveryGate` / `MINI_CODE_SKILL_DISCOVERY_GATE`。
2. **正文独占评测集**（`cases-exclusive.json`，SHA-256 `ac5cc75758c6…`）：8 个新正例（E01–E08），答案必需的流程常量只存在于技能正文，证据文件只含原始数据与 policy_source 指针；已逐常量验证全工作区唯一命中 SKILL.md。期望值由 `check_expected.py` 从常量独立重导出自检。负例沿用 N01–N08。

模型 glm-5.3-flash；7 个只读工具；16 步/16 调用预算；并发 4；逐试验隔离工作区。四批共 216 轮真实 Agent Loop。私有 runtime（含凭据）在批后删除。

## 二、核心对照

### 旧模糊集（20 题：12 正例 + 8 负例 ×3）

| 指标 | A：无 gate | B：gate 开 |
|---|---:|---:|
| 正例发现发起 /36 | 8（22.2%） | **27（75.0%）** |
| 检索+正文交接 /36 | 8（22.2%） | **27（75.0%）** |
| 发起后链路成功率 | 8/8 | 27/27 |
| 负例正文误触发 /24 | 0 | **0** |
| 任务 JSON 验收（正例）/36 | 27 | 27 |
| gate nudge 实际注入 | — | 22 次 / 60 轮 |
| 整轮输入 token 均值 | 18,775 | 28,607（+52%） |
| 整轮输出 token 均值 | 680 | 1,033 |

分项：R01–R04 与 C01–C04 全部升到 3/3 发现；**X01–X03 仍为 0/3**（X04 为 3/3）。X 类未升的原因是门控信号来自路由建议，而 X 类（新增能力目录）的建议命中为 0——gate 放大现有建议信号，不能无中生有。

### 独占集（8 正例 + 8 负例 ×3）

| 指标 | A：无 gate | B：gate 开 |
|---|---:|---:|
| 正例发现发起 /24 | 24（100%） | 24（100%） |
| 检索+正文交接 /24 | 22（91.7%） | 21（87.5%） |
| 答案正确（格式容错）/24 | 20（83.3%） | — |
| 严格 JSON 验收（正例）/24 | 10 | 13 |
| 负例误触发 /24 | 0 | 0 |
| gate nudge 注入 | — | 6 次 / 48 轮 |

独占集上 gate 开与关结果在噪声内持平：任务真正需要技能正文时，发现自发率已是 100%，门控几乎不触发（6/48）也不改变结果——**零开销无害性成立**。严格 JSON 验收显著低于格式容错正确率（10 vs 20），与三臂实验已记录的"JSON 外附说明被拒"现象一致，不代表事实回答错误。

## 三、结论

1. **门控有效**：模糊任务下的技能发现发起率 22.2% → 75.0%（+52.8pp），且链路完整性保持 100%（凡发起必交接）、负例零误触发保持。
2. **门控无害**：在不需要它的场景（独占集）几乎零触发、结果持平；代价是模糊集整轮输入 +52%（多出的发现轮次），这是把"不行动"变成"行动"的直接成本。
3. **触发问题已在机制层关闭**：建议通道决定"看哪"，门控保证"必须看"；剩余缺口是 X 类新能力目录的建议命中为 0（信号源问题，非门控问题）。
4. **评测校准成功**：正文独占设计使"发现/检索/回答"全链路可测，消除了旧评测"合理裸答"对采用率的稀释。

## 四、可声明的简历口径（全部可复核）

> 实现模型驱动的两级 Skill 路由（目录卡渐进披露 + 按需加载 + 可选发现门控）：千级目录首轮输入较全量平铺降低约 79%；在正文独占信息基准上技能发现发起 100%、正确加载与正文交接 91.7%、答案正确率 83.3%（格式容错）；发现门控将模糊任务下的发现发起率从 22% 提升至 75%，且负例零误触发、无门控场景零开销；全部结论经 500+ 轮冻结协议真实 Agent Loop 对照与独立审计。

面试追问点（诚实口径）：X 类新能力目录建议命中为 0 是遗留缺口；严格 JSON 验收受输出格式纪律拖累（历史已知现象）；门控在模糊任务上以约 +52% 整轮输入为代价。
